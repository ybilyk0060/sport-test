# Веб-тест «Який спорт підійде дитині»

Страница в браузере: квиз (6 вопросов) → камера и 5 упражнений → результат → подписка → полный отчёт и программа тренировок.
Тестовая версия: настоящих платежей нет, данные хранятся на устройстве, от поисковиков закрыта.

- Отчёт владельцу: [docs/OWNER-REPORT.md](docs/OWNER-REPORT.md)
- Утренняя проверка на телефонах: [docs/CHECKLIST.md](docs/CHECKLIST.md)

## Запуск

Сборки нет — обычные файлы. Локально:

```bash
python3 -m http.server 8080
```

Камера работает только по https или на localhost.

## Проверка

```bash
npm test
```

## Настройки

Режим пейвола, цена подписки, цели упражнений, ссылки на приложения — `js/config.js`. Программа подписчика — `js/program.js`.
Голос (Achird из Студії вправ): `node tools/fetch-voice.mjs` скачивает клипы по манифесту студии. Тексты — `js/i18n/uk.js`.
Диагностика на телефоне — добавить `?debug=1` к адресу.
