### Заглушки

1. **Оплата** — тестовая страница `pay-test.html`. Провайдер подключается в `js/payment.js` (два метода), без переделки страницы.
2. **Хранение данных** — на устройстве (localStorage). Сервера нет: вы не видите ответы, контакты и события других людей. См. вопрос 2.
3. **Отправка результата на контакт** — контакт сохраняется, но никуда не отправляется (нет сервера и бота).

5. **Контакт продавца в политике** — пустое место, заполнить до рекламы.
6. **Политика конфиденциальности** — отдельный файл `privacy.html` (не в общем файле строк): при добавлении en/de делается `privacy-en.html`.

### НЕ проверено (нужен живой телефон и ребёнок)

1. **Камера во встроенном браузере Instagram и Facebook** на iPhone и Android — главная утренняя проверка.
2. **Счёт на живом человеке в браузере.** Движок проверен на синтетических позах; через камеру с настоящим ребёнком — нет (в облаке нет ни камеры, ни видео человека).
3. **Скорость на телефоне** (кадров в секунду). Ниже ~12 счёт прыжков начнёт теряться — смотрите в `?debug=1`.
4. **Звук на iOS одновременно с камерой** во встроенном браузере (может быть тихим или идти в разговорный динамик).
5. **Кнопка «Відкрити в Safari»** (`x-safari-https://`) — работает с iOS 17, на старых версиях не сработает; рядом есть текстовая инструкция.
6. **Видео с пандой** — берутся прямо из хранилища каталога студии; из облака этот адрес закрыт, не видел их на экране. Если не загрузятся, останутся текст и голос.
7. **Разбор записи** (запасной путь) на iPhone: формат HEVC/MOV в Safari играет, в Chrome на Android чужие форматы могут не открыться.
8. **Планка с телефоном в руках** — упражнение на полу, кадр другой. Возможно, для 4–6 лет её стоит заменить (вопрос 5).

## 2. Какой движок взят и как сверен счёт

**Выбор: оригинальный движок студии Kidsney, без переноса и без правок.**

- Оригинал написан на TypeScript. Исходники (`~/dev/kidsney`) и перенос на Dart с фикстурами (`/Volumes/KidsneyDrive/...`) из облачной сессии недоступны: Mac не отдаёт эти папки.
- Поэтому движок взят из публичной сборки студии (`kidsney-demo/studio`, сборка из kidsney `09c55bebf`): вырезан цельный фрагмент — геометрия, калибровка по возрасту, сглаживание, анализатор кадров, движок спеков. 41 435 символов, ноль внешних зависимостей. Файл: `js/engine/kidsney-engine.js`, в шапке — контрольная сумма фрагмента.
- Минус: код минифицирован (имена короткие). Читать его неудобно, но он идентичен боевому. Когда появится доступ к исходникам — заменить файл на собранный из TS, интерфейс тот же.

**Спеки упражнений** — из опубликованного каталога (та же таблица, что отдаёт `exercise-catalog`; сама функция из облака закрыта сетью, читал базу только на чтение, только опубликованные строки):

| Упражнение | Версия | md5 спека совпал с каталогом |
|---|---|---|
| squats | 3 | да |
| jumping_jack | 4 | да |
| high_knees | 2 | да |
| plank | 1 | да |

**Сверка счёта** (`tests/engine.test.mjs`, `tests/session.test.mjs`):

- Позы — из QA-имитатора самой студии (`mockPoseFrameSource`): приседание, планка, бег с коленями. Для прыжков имитатора в студии нет — написан свой генератор.
- Приседания: 1, 5, 8 повторов → 1, 5, 8 засчитано (возраст 5, 8, 11). Неглубокие — 0.
- Прыжки: 1, 6, 10 → 1, 6, 10. Только руки или только ноги — 0.
- Бег с коленями: 40 подъёмов → 40 засчитано. Низкая ходьба — 0.
- Планка: 20 с неподвижно → 18,9 с (минус секунда на вход). Стоящий человек — 0.

**Не сверено:** на фикстурах Dart-переноса (нет доступа) и на записях живых детей.

## 4. Правила: как получается профиль

Норм по возрасту нет. Ребёнок сравнивается с заданием, не с другими детьми. На экране так и написано: «попередній результат».

**Показатели (каждый от 0 до 1):**

| Показатель | Как считается |
|---|---|
| Задание выполнено | сделано / цель (для всех 4 упражнений) |
| Ритм прыжков | 1 − разброс интервалов / 0,5 (нужно ≥ 3 прыжка) |
| Чистота приседаний | засчитано / (засчитано + подсказок «ниже») |
| Темп бега | активные секунды / всё время с первого шага |
| Устойчивость планки | 1 − дрейф корпуса в градусах / 10 (10° — порог из спека студии) |
| Симметрия рук | 1 − разница высоты кистей / 0,3 длины туловища |
| Симметрия ног | меньшее число подъёмов / большее (левая и правая) |

**Качества = среднее своих показателей:**

| Качество | Показатели |
|---|---|
| Координація | прыжки: задание + ритм |
| Сила ніг | приседания: задание + чистота |
| Швидкість | бег: задание + темп |
| Стабільність корпусу | планка: задание + устойчивость |
| Симетрія рухів | симметрия рук + симметрия ног |

**Уровни:** ≥ 0,75 — «Сильна сторона»; ≥ 0,45 — «Добре, є запас»; ниже — «Зона росту»; упражнение пропущено — «Не виміряно».

Пороги 0,75 / 0,45 / 0,5 / 0,3 — рабочие, выбраны мной, не из исследований. После 50–100 прохождений их нужно пересмотреть по реальному разбросу. Все в `js/config.js` и `js/scoring.js`.

Если измерено меньше двух качеств — отчёт не продаётся, показывается «Замало даних» и кнопка «Пройти тест ще раз».

## 5. Правила: как ответы квиза влияют на рекомендации

**Три направления** — у каждого из 8 направлений копятся баллы, берутся три лучших.

| Ответ | Баллы |
|---|---|
| Любит: команда и мяч | командные +4, ракетка +1 |
| Любит: сам по себе | плавание +2, лёгкая атлетика +2, ракетка +2 |
| Любит: музыка и танцы | танцы +4, гимнастика +1 |
| Любит: борьба и сила | единоборства +4 |
| Любит: лазить и прыгать | скалолазание/паркур +4, гимнастика +2 |
| Характер: очень активный | командные +1, единоборства +1, лёгкая атлетика +1 |
| Характер: спокойный | плавание +1, ракетка +1, танцы +1 |
| Цель: здоровье и осанка | плавание +2, гимнастика +1 |
| Цель: дисциплина | единоборства +2, гимнастика +1 |
| Цель: уверенность | единоборства, командные, танцы, скалолазание по +1 |
| Цель: результат | лёгкая атлетика, гимнастика, ракетка, плавание по +1 |
| Возраст 4–6 | гимнастика, танцы, плавание по +1 |

**Качества из теста** («есть запас» — половина веса, «сильная сторона» — полный вес):

| Качество | Куда добавляет |
|---|---|
| Координація | танцы 2; командные, гимнастика, единоборства, скалолазание, ракетка по 1 |
| Сила ніг | лёгкая атлетика, единоборства, скалолазание по 1 |
| Швидкість | лёгкая атлетика 2; командные, ракетка по 1 |
| Стабільність корпусу | гимнастика 2; единоборства, плавание, скалолазание по 1 |
| Симетрія рухів | гимнастика, танцы, плавание по 1 |

Желание ребёнка (до 4 баллов) весит больше любого одного качества (до 2). Под каждым направлением в отчёте — до трёх причин, откуда баллы.

**Остальные ответы:**

| Ответ | На что влияет |
|---|---|
| Возраст | набор и цели упражнений, калибровка движка |
| Сейчас ничем не занимается | совет: начать с двух занятий в неделю |
| Ходит в секцию | совет: показать профиль тренеру |
| Экран больше 3 часов | совет: двигательная пауза после каждого часа |
| Город | строка «ищите пробные занятия в городе N». Базы секций нет. |
| Время с экраном «до 1 ч», «1–3 ч» | пока ни на что. Собираем для статистики. |

**План на 2 недели:** 3 занятия в неделю × 3 упражнения. Два — на самые слабые качества, одно — на самое сильное. Неделя 1 — собственный результат ребёнка в тесте (не ниже минимума), неделя 2 — на шаг больше (+2 повтора или +5 с). Упражнения только из каталога студии с возрастом 4+.

## 8. Вопросы владельцу (без них дальше нельзя)

1. **Кто продавец?** ФОП или ТОВ, какая группа, в каком банке счёт. От этого зависят провайдер, оферта, условия возврата и контакты на сайте.
2. **Где держать сервер** для данных и подтверждения оплаты: (а) таблица и функция в проекте Supabase Kidsney, (б) новый отдельный бесплатный проект, (в) пока ничего — тогда настоящую оплату подключить нельзя.
3. **Сумма в гривне.** Сейчас 210 грн. Подтвердите сумму или дайте курс.
4. **Адрес сайта.** Тестовый адрес на github.io делит домен с kidsney-demo. Для рекламы нужен отдельный домен — какой?
5. **Планка для 4–6 лет:** оставить, заменить или убрать (тогда у малышей 3 упражнения).
